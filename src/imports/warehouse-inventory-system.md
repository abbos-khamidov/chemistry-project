Design a professional, production-ready, responsive web application UI for a real company warehouse and inventory management system for goods and chemicals. This is not an MVP, startup concept, or portfolio design. It must feel like a reliable enterprise/business product used daily by staff in real operations.

The interface should be minimal, modern, clean, highly practical, and operational. Focus on clarity, speed, transparency, readability, and strong UX for real business workflows. Avoid decorative concepts, flashy visuals, unnecessary gradients, or trendy effects that reduce usability.

Style:
- Professional enterprise SaaS interface
- Minimal and structured layout
- Clear hierarchy
- Clean spacing
- Rounded cards and inputs
- Soft subtle shadows
- Neutral corporate color palette
- High readability
- Strong table and form usability
- Clear status colors for stock, debts, overdue items, alerts
- Responsive design for desktop, tablet, and mobile

Footer:
On every page add a subtle professional note:
“Сделано aisolution.uz”

Roles:
1. Owner — full access to all functions, analytics, reports, users, settings
2. Manager — manage products, stock, debts, reports, limited administrative access
3. Worker — operational access for inventory viewing, search, quantity updates if permitted, debt/service entry creation

Main pages:

1. Login / Registration
Clean, secure auth pages with sign in and sign up.
Fields: full name, phone, email/login, password.
Corporate and trustworthy appearance.

2. Main Dashboard
Show key business metrics:
- total products
- low stock items
- total warehouse value
- monthly operations
- active debts
- overdue debts
- recent activity
- quick actions
Include charts and analytics widgets.
Role-based content visibility.

3. Products / Inventory
Professional inventory management page with both table and card views.
Functions:
- search
- filter
- sort
- add product
- edit product
- delete product
Fields:
- product name
- category
- quantity
- unit
- price
- supplier
- expiration date
- status
- notes
Make it suitable for chemicals and warehouse stock control.

4. Product Detail Page
Detailed product information page with:
- stock history
- quantity changes
- price history
- expiry information
- status
- notes
- related actions
Structured and clear layout.

5. Debts Page
Dedicated debt management module.
Debt format:
- full name
- phone
- debt amount
- product
- quantity
- issue date
- due date
- status
Allow search, filter, and detailed viewing.
Statuses: active, overdue, paid, partial payment.

6. Debt Detail Page
Detailed debt profile/page showing:
- full name
- phone
- all products taken
- quantities
- total amount
- paid amount
- remaining debt
- issue date
- due date
- notes/comments
- payment history
- debt status
Actions:
- add payment
- mark as paid
- edit
- export or print

7. Analytics & Reporting
Serious reporting interface for real management use.
Show:
- monthly analytics
- custom period reports
- inventory movement
- top categories
- most used products
- debt growth
- paid vs unpaid debts
- warehouse value over time
Include date range picker and export actions.

8. Users / Roles Management
User management page with:
- full name
- phone
- role
- status
- last activity
Actions:
- add user
- edit user
- deactivate user
- manage permissions by role

Navigation:
Create a highly usable enterprise navigation system.
Desktop:
- left sidebar
- top header
Mobile:
- bottom navigation or drawer
Navigation items:
- Dashboard
- Products
- Debts
- Analytics
- Users
- Settings
Header should include:
- global search
- notifications
- user profile
- role label
