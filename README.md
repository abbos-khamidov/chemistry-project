# Warehouse Management System UI

MVP веб-интерфейса корпоративной системы учёта склада (товары, химикаты). Сделано для демонстрации и деплоя на Vercel.

## Роли

- **Директор** — только разделы **Аналитика**, **Аудит** (журнал действий), **KPI работников** (показатели по каждому рабочему). Доступа к товарам в меню нет.
- **Рабочий** — только **Товары** (список и карточка). Регистрация нового пользователя всегда создаёт роль «рабочий».

Данные в MVP — моковые (`src/app/data/mockData.ts`). Старые роли в localStorage при открытии приложения автоматически приводятся к `director` / `worker`.

## Возможности MVP

- **Вход и регистрация** — логин по email/паролю, регистрация (данные в localStorage).
- **Защищённые маршруты** — без входа открывается только страница входа; маршруты зависят от роли.
- **Аналитика (директор)** — метрики и графики по складу и долгам, кнопка «Экспорт».
- **Аудит (директор)** — таблица событий (демо).
- **KPI работников (директор)** — операции, точность, сроки по каждому рабочему.
- **Товары (рабочий)** — список, поиск и фильтры, карточки и таблица, детальная страница.
- **Выход** — меню профиля в шапке.

## Демо-доступ

После первого запуска в localStorage подставляются тестовые пользователи:

| Роль      | Вход (логин или email) | Пароль  |
|-----------|------------------------|--------|
| Директор  | **diyor** или diyor@warehouse.uz | **1234** |
| Рабочий   | worker@warehouse.uz    | demo123 |
| Рабочий   | sevara@warehouse.uz    | demo123 |

Роль после входа берётся из сохранённой учётной записи (поле `role`): директор один — с логином `diyor`.

Регистрация создаёт учётную запись с ролью **рабочий**.

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 (или порт, который покажет Vite).

## Сборка

```bash
npm run build
```

Результат в папке `dist/`.

## Деплой на Vercel

1. Подключите репозиторий к Vercel.
2. **Build Command:** `npm run build`
3. **Output Directory:** `dist`
4. **Install Command:** `npm install` (или `pnpm install`)

Файл `vercel.json` настроен так, что все маршруты отдаются через `index.html` (SPA).

## Стек

- React 18, Vite, React Router 7
- Tailwind CSS 4
- Recharts (графики), Sonner (toast-уведомления), Lucide (иконки)

## Структура

- `src/app/context/AuthContext.tsx` — авторизация (localStorage), роли `director` / `worker`, миграция старых ролей.
- `src/app/components/RoleGate.tsx` — редиректы по ролям для маршрутов.
- `src/app/components/Layout.tsx` — сайдбар и нижняя навигация (разные пункты для директора и рабочего).
- `src/app/pages/` — Login; для директора: Analytics, Audit, WorkerKPI; для рабочего: Products, ProductDetail.
- `src/app/data/mockData.ts` — моковые товары, долги, пользователи, журнал аудита и KPI работников.
