# Warehouse Management System UI

MVP веб-интерфейса корпоративной системы учёта склада (товары, химикаты, долги клиентов). Сделано для демонстрации и деплоя на Vercel.

## Возможности MVP

- **Вход и регистрация** — логин по email/паролю, регистрация (данные в localStorage).
- **Защищённые маршруты** — без входа открывается только страница входа.
- **Дашборд** — сводка по товарам, долгам, стоимости склада и быстрые действия.
- **Аналитика** — метрики и графики по данным склада и долгов, кнопка «Экспорт» с уведомлением.
- **Товары** — список, поиск и фильтры, карточки и таблица, сброс фильтров.
- **Долги** — список с поиском и фильтром по статусу, сброс фильтров.
- **Пользователи** — список, кнопки «Добавить», «Редактировать», «Деактивировать» (тосты).
- **Настройки** — форма с кнопками «Сохранить» и «Отмена» (тосты).
- **Выход** — выпадающее меню профиля в шапке с кнопкой «Выйти».

Данные в MVP — моковые (файл `src/app/data/mockData.ts`). Кнопки добавления/редактирования пока показывают уведомления (toast).

## Демо-доступ

После первого запуска в localStorage подставляются тестовые пользователи:

| Роль    | Email                | Пароль  |
|--------|----------------------|--------|
| Owner  | owner@warehouse.uz   | demo123 |
| Manager| manager@warehouse.uz | demo123 |
| Worker | worker@warehouse.uz  | demo123 |

Можно также зарегистрировать нового пользователя (роль по умолчанию — worker).

## Запуск локально

```bash
npm install
npm run dev
```

Откройте http://localhost:5173 (или порт, который покажет Vite).

## Сборка

```bash
npm run build
```

Результат в папке `dist/`.

## Деплой на Vercel

1. Подключите репозиторий к Vercel.
2. **Build Command:** `npm run build`
3. **Output Directory:** `dist`
4. **Install Command:** `npm install` (или `pnpm install`)

Файл `vercel.json` настроен так, что все маршруты отдаются через `index.html` (SPA).

## Стек

- React 18, Vite, React Router 7
- Tailwind CSS 4
- Recharts (графики), Sonner (toast-уведомления), Lucide (иконки)

## Структура

- `src/app/context/AuthContext.tsx` — авторизация (localStorage).
- `src/app/components/Layout.tsx` — сайдбар, шапка, меню пользователя, футер «Сделано aisolution.uz».
- `src/app/pages/` — страницы: Login, Dashboard, Products, Debts, Analytics, Users, Settings и детальные страницы товара/долга.
- `src/app/data/mockData.ts` — моковые товары, долги, пользователи и статистика для дашборда/аналитики.
